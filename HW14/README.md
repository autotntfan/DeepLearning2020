Create yolo.h5
===
Download three files：<\br>
[yolo.cfg](https://github.com/pjreddie/darknet/blob/master/cfg/yolov2.cfg)  change name from yolov2.cfg to yolo.cfg <\br>
[yolo.weights](http://pjreddie.com/media/files/yolo.weights) <\br>
[yadk.py](https://github.com/allanzelener/YAD2K/blob/master/yad2k.py)       change name from yad2k.py to yadk.py <\br>
Open cmd and write on <\br>
./yadk.py yolo.cfg yolo.weights model_data/yolo.h5 <\br>
